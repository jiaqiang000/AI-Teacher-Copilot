## 运维边界

共享体验账号仅限演示数据，具有已有账号的普通业务权限，并非只读沙箱。不要向体验身份放入真实师生隐私数据。
复用已初始化的 seed 账号；登录不会创建账号、重置密码或修改业务映射。缺失、密码被改、映射不符、数据库不可用均返回 503；管理员和需要初始化的账号不能从演示入口登录。

部署需重启 Gateway 并重新构建生产前端；本地正在运行的旧生产进程不会自动读取此改动。
