## GitHub 之外的社区反馈

### 开发者博客与评论

- 没有语义搜索（注入基于置信度，而非相关性）
- 没有语义去重（仅基于文本比较）
- 100 条事实上限，并采用基于置信度的淘汰机制
- 通过聊天删除内存不可靠

### 社区生态系统

- 一个 **DeerFlow Trace Edition** 分支，内置执行流程检查（无需 LangSmith）
- 一个 **OAuth 网桥**，使 DeerFlow 能够在没有 API 密钥的情况下使用 ChatGPT Plus/Pro 订阅
- 一个基于 DeerFlow 构建的**技术研究与评估 Agent**
- 多个**飞书/Lark 集成**项目
